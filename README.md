# Velix Go Motorista - Aplicativo do Parceiro 🚘 🏍️

Aplicativo móvel independente para motoristas e mototaxistas parceiros receberem chamadas em tempo real, navegarem até o passageiro e destino, controlarem seus ganhos diários/semanais e gerenciarem o pagamento de taxas da plataforma (R$ 0,50 por corrida) via Pix.

## 📱 Tecnologias
- **Flutter & Dart** (Material Design 3)
- **Supabase Backend** (Auth, PostgreSQL, Realtime, RLS)
- **Google Maps SDK**
- **Arquitetura**: Clean Architecture & Provider State Management

## 📦 Identificadores do Build
- **Pubspec Name**: `velix_go_driver`
- **Android Package / Application ID**: `com.velixgo.driver`
- **App Name**: `Velix Go Motorista`

## 🚀 Como Executar e Compilar

### 1. Obter dependências:
```bash
flutter pub get
```

### 2. Executar em modo Debug:
```bash
flutter run
```

### 3. Gerar APK de Produção independente:
```bash
flutter build apk --release
```

### 4. Executar Testes:
```bash
flutter test
```
